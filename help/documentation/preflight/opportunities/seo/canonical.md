# Canonical audit

The **Canonical** audit reviews the canonical link on your page. A correct canonical link tells search engines which URL is the authoritative version of a page, which helps avoid duplicate-content problems. The audit flags canonical links that are missing or incorrect.

When the audit finds opportunities, each one describes the problem and the recommended change. To learn how to review and resolve opportunities, see [Audit results in Preflight](../../audit-results.md).
