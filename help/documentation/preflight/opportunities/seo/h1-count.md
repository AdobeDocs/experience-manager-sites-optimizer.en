# H1 count audit

The **H1 count** audit reviews the number of H1 headings on your page. A page should generally have a single, descriptive H1 that summarizes its content. Missing or multiple H1 headings can weaken the page's structure and its search engine optimization.

When the audit finds opportunities, each one describes the problem and the recommended change. To learn how to review and resolve opportunities, see [Audit results in Preflight](../../audit-results.md).
