# Links audit

The **Links** audit reviews the links on your page. Broken or insecure links harm the user experience and can reduce how effectively search engines crawl your site. The audit flags links that need attention so you can fix them before publishing.

When the audit finds opportunities, each one identifies the affected link and describes the recommended change. To learn how to review and resolve opportunities, see [Audit results in Preflight](../../audit-results.md).
