# Lorem ipsum audit

The **Lorem ipsum** audit detects placeholder text that has been left in your page content. Publishing a page with placeholder text looks unfinished to readers and can be indexed by search engines. The audit flags any placeholder text so you can replace it with real content before publishing.

When the audit finds opportunities, each one identifies where the placeholder text appears. To learn how to review and resolve opportunities, see [Audit results in Preflight](../../audit-results.md).
