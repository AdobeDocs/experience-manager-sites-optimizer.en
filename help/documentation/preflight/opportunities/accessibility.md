# Accessibility audits

![Accessibility audits in the Preflight readiness dashboard](./assets/accessibility/hero.png){align="center"}

The **Accessibility** audit in Preflight evaluates your page against the Web Content Accessibility Guidelines (WCAG) to help ensure the page is usable by everyone, including people with disabilities. When you run a Preflight audit, it evaluates the page against these accessibility standards and groups the issues it finds into opportunities you can review and resolve before publishing. For more about the accessibility checks and the guidelines they cover, see [Accessibility issues](/help/documentation/opportunities/accessibility-issues.md).

In the readiness dashboard, expand the **Accessibility** category to see whether the audit passed and the number of opportunities it found. Select the audit to open its detail page and work through the opportunities. Each opportunity describes the accessibility issue, its severity, and the related WCAG rule and conformance level, along with the affected element on the page. When the element has readable text, Preflight shows that text so you can recognize the element more easily; otherwise it shows the element's CSS selector. To learn how to interpret results and resolve opportunities, see [Audit results in Preflight](../audit-results.md).
